# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private vulnerability reporting: on the repository,
go to **Security > Report a vulnerability** (Security Advisories). Include the Vortex version, what
you did, and what happened. Logs must have secrets removed first.

You can expect an acknowledgement as soon as the maintainer sees it; fixes ship in a new release.
